# 📊 Arduino Sensor Monitor

Простое Windows-приложение на C#, которое считывает данные с датчиков через Arduino Uno и отображает их в удобном виде.

---

## 🧪 Описание проекта

Проект позволяет:

- Считывать температуру и влажность с датчика **DHT11 / DHT22**
- Измерять уровень освещённости через **фоторезистор**
- Выводить всё в реальном времени через COM-порт
- Отображать данные в **Windows Forms** приложении

---

## 💻 Windows Forms Приложение

![Windows Form](image/wf.jpg)

В приложении отображаются:

- Температура (°C)
- Влажность (%)
- Яркость (0–1023)
- Лог данных в реальном времени

---

## 🧩 Компоненты

| Компонент                   | Количество    |
| --------------------------- | ------------- |
| Arduino Uno                 | 1 шт.         |
| DHT11 или DHT22             | 1 шт.         |
| Фоторезистор                | 1 шт.         |
| Резистор 10 кОм             | 2 шт.         |
| Макетная плата (breadboard) | 1 шт.         |
| Соединительные провода      | несколько шт. |

---

## ⚙ Как собрать проект

### Для Arduino:

1. Залей скетч через Arduino IDE
2. Подключи датчики по схеме
3. Проверь вывод в монитор порта

### Для Windows Forms:

1. Открой проект в SharpDevelop или Visual Studio
2. Подключи Arduino
3. Запусти программу
4. Выбери COM-порт и подключись

---

## 🌐 Протокол обмена

Arduino выводит данные в формате:
24.0°C 45% 380
(через табуляцию: температура → влажность → яркость)
